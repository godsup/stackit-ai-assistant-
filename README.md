# StackIT AI Assistant

This repository contains the project structure for the StackIT AI Assistant.

## Structure

- `backend/` – backend services and APIs
- `frontend/` – frontend application
- `docs/` – project documentation
- `infrastructure/` – infrastructure and deployment files

## Getting Started

1. Review the backend and frontend folders.
2. Add implementation details and configuration.
3. Update documentation in the `docs/` folder.
