# Manage auth tokens

### Prerequisites

Before creating an auth token, ensure you meet the following prerequisites:

- You have a STACKIT customer account
- You have a STACKIT user account
- You have a STACKIT project

## Purpose of auth tokens and how to manage them

With auth tokens you authenticate the clients against the AI Model Serving. Every API access to the service needs to be authenticated. In this article, you learn how to manage your auth tokens.

## Create an auth token

1. On the sidebar, click on AI Model Serving.
2. Click on the instance for which you want to create an auth token.
3. In the top bar, click Create token.
4. Enter a token name and optionally a lifetime.
5. Click Order fee-based.
6. Copy the generated token to a safe place. You cannot retrieve the token afterwards.

## List auth tokens

1. On the sidebar, click on AI Model Serving.
2. You see a list of all tokens. Click on a token to view the details pane.

There is no possibility to retrieve the token. If you lost your token, you need to create a new one.

## Update auth tokens

1. On the sidebar, click on AI Model Serving.
2. You see a list of all tokens. Click on a token to view the details pane.
3. Click Save to update the token.

## Delete auth tokens

1. On the sidebar, click on AI Model Serving.
2. You see a list of all tokens. Click on a token’s three dots button and then on Delete to open the delete pane.
3. Enter the token name and click Delete to finally delete the token.
